# مرسم كوكو (Koko Painter)

تطبيق رسم وتلوين للأطفال باللغة العربية (RTL) — يعمل كتطبيق ويب تقدمي (PWA) على الهاتف أو الجهاز اللوحي.

## الميزات

- غرفة رسم مع قلم، قوس قزح، فرشاة سحر، فرشاة بريق، وتعبئة (Bucket)
- تراجع / إعادة
- قوالب تلوين ورفع صورة
- ملصقات عادية ونادرة تُفتح بالنجوم
- احتفال كبير عند الحفظ مع رسائل تشجيع شخصية
- صوت كوكو يشجّع بالعربية (Web Speech)
- مفاجأة يومية (ملصق أو نجوم)
- 15 رسمة جاهزة للتلوين
- مشاركة اللوحة مع إطار جميل لماما/بابا
- معرض اللوحات والجوائز ومستويات التقدم
- منطقة والدين محمية برمز PIN
- عمل دون اتصال بعد أول زيارة (Service Worker)

## التشغيل المحلي

لا تفتح الملفات مباشرة بـ `file://` — استخدم خادماً محلياً:

```bash
# Python
python -m http.server 8000

# أو Node
npx --yes serve -l 8000
```

ثم افتح: [http://127.0.0.1:8000](http://127.0.0.1:8000)

## تثبيت كتطبيق (PWA)

1. افتح التطبيق عبر `http://localhost` أو عبر **HTTPS**.
2. من الصفحة الرئيسية استخدم زر التثبيت إن ظهر، أو «إضافة إلى الشاشة الرئيسية» من المتصفح.

## الخصوصية

كل البيانات (الاسم، اللوحات، النجوم، الملصقات، PIN) تُحفظ فقط في `localStorage` على الجهاز. لا يوجد مزامنة سحابية ولا تحليلات خارجية.

## هيكل المشروع

| ملف | الدور |
|-----|--------|
| `index.html` | الترحيب والقائمة |
| `studio.html` + `drawing.js` | غرفة الرسم |
| `gallery.html` + `js/gallery.js` | المعرض |
| `reward.html` | النجوم والمستويات |
| `parent.html` | منطقة الوالدين |
| `storage.js` | التخزين المحلي |
| `service-worker.js` | التخزين المؤقت دون اتصال |
| `manifest.json` | بيانات PWA |

## ملاحظات للتطوير

- بعد تعديل ملفات الكاش، زد رقم الإصدار في `service-worker.js` (`CACHE_NAME`).
- الملصقات النادرة تُفتح عند 5 / 15 / 30 نجمة.
